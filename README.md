# Retail Sales SQL Analysis

SQL queries answering business questions on a retail sales dataset (1,000 transactions).

## Skills shown

- Filtering, sorting, GROUP BY / HAVING
- Joins and subqueries
- Window functions: RANK, ROW_NUMBER, running totals, LAG

## Files

- `queries.sql`: all queries, each with the business question it answers

## Example question

"What are the top 3 transactions in each product category?"
